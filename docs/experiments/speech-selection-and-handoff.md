# 语音选择、字幕编辑与实验声纹：组员接力说明

本分支基于 `feature/mec-offloading` 的 `1f54c9e`，已包含此前的人脸静态/动态卸载与嘴部归属代码。它是根据进展汇报重新实现的接力版本，并未取得开发电脑中尚未提交的源文件。

## 使用方式

1. 按 README 构建、安装 APK。无需清除旧应用数据；数据库从版本 1 升到 2 时仅新增声纹表。
2. 在“实时转写”选择本地中文、本地英文或电脑端中英。选择会保存，下一次开始采集时生效。中文沿用内置 Vosk 模型；电脑端中英沿用 FunASR，失败时回退到本地中文。英文模式缺少模型时显示导入提示，不会偷偷切换语言或上传音频。
3. 英文模型从 [Vosk 官方模型目录](https://alphacephei.com/vosk/models)下载 `vosk-model-small-en-us-0.15.zip`，停止采集后点击“导入英文 Vosk 模型 ZIP”，选择原始 ZIP。文件复制到应用私有存储。无需额外存储权限，也不必重新构建 APK。
4. 在“已保存转写”点按任意记录可修改文字；不能为空，保存后更新同一条 SQLite 记录。原时间、说话人和其他记录不变；重启后应保留修改。清空历史后，已打开的编辑框不能重新创建被删除的记录。

## 实验声纹辅助

- 从同一官方目录下载 `vosk-model-spk-0.4.zip`，使用“导入 Vosk 声纹模型 ZIP”。不要把模型文件夹重新随意打包；导入器检查基本结构、防止路径越界，并限制解压体积为 300 MiB。
- 选择本地中文或本地英文，勾选“实验声纹辅助”后开始采集。电脑端 FunASR 模式不使用这项功能。
- 先登记人脸，点选该身份，点击“为选中身份录入下一句声纹”。本人明确同意后，仅由本人清晰说一段至少数秒的话并停顿，等待最终识别结果。只有至少 300 个声纹帧且包含有效 128 维向量的结果才会录入；不满足时继续等待，可停止采集取消。再次录入会覆盖该身份的旧声纹。
- 后续最终结果通过余弦相似度匹配。临时字幕仍使用视觉归属；有效声纹可补充视觉证据不足的最终归属；若两者冲突则保留“未确认说话人”。没有足够声纹证据时沿用原有嘴部判断。
- 阈值（相似度 0.75、领先第二名 0.15）是尚未通过真实人群校准的实验参数，不代表已验证准确率，也不能用于身份认证。录入时请避免其他人讲话；本版本不做重叠语音分离、防重放或活体声纹检测。
- 声纹仅保存在应用本机；身份重命名/删除时同步处理声纹。可以单独清除全部声纹，保留人脸和字幕。应用不保存原始录音。

## 主要文件

| 文件（Android 源码目录下） | 职责 |
| --- | --- |
| `SpeechMode.kt` | 三种语音执行模式 |
| `MainActivity.kt` | 选择、模型导入、字幕编辑、声纹录入及归属集成 |
| `ModelArchive.kt` | 检查并安装模型 ZIP，导入失败保留原模型 |
| `VoskSpeechEngine.kt` | 本地识别以及 Vosk 说话人向量提取 |
| `SpeechEngine.kt` | 携带声纹向量和有效帧数的语音事件 |
| `VoiceprintMatcher.kt` | 向量校验、相似度和歧义拒绝 |
| `LocalStore.kt` | 字幕按 ID 修改、声纹存储和无损数据库升级 |

## 验证与待办

运行 `bash gradlew :app:testDebugUnitTest :app:assembleDebug`。新增测试覆盖模型 ZIP 导入与失败保留、路径越界拒绝、声纹有效性与歧义拒绝，以及声纹随最终语音事件传递。

云环境没有 Android 设备；尚未验证界面交互、SQLite 真机升级/编辑持久化、官方英文/声纹模型实际加载，以及真人英文识别和声纹归属效果。官方下载域名在该环境被网络策略阻止，模型未随本次代码提交；组员需要自行从官方目录下载并导入，检查对应许可。

真机验收请逐项记录：三种模式切换和缺模型提示、英文识别、FunASR 断连中文后备、停止/重启采集、字幕修改与重启、重复同文字幕只修改被选记录、旧数据库升级、身份重命名/删除的声纹联动、取消和清除声纹、单人和多人轮流讲话的误归属率。五组静态组合、动态策略和能耗实验仍需另行完成。
